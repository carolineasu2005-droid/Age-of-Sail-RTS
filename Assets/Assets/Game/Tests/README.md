# Sailing Regression Tests

Run the complete suite in Unity through **Window > General > Test Runner**.

1. Open the **EditMode** tab and select **Run All**.
2. Open the **PlayMode** tab and select **Run All**.
3. Keep the Console visible and investigate any failed test before accepting a gameplay change.

The automated suite covers deterministic math, geometry, selection, command payload, and runtime state ownership. Use the manual smoke checklist for visual quality and interaction feel.
